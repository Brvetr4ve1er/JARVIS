## Frameworks Overview

Beyond individual master prompts, JARVIS includes several integrated frameworks for tackling complex problems:

### 1. **The CLEAR Framework**
For creating clear, effective communication:
- **C**ontext: Establish background and scope
- **L**earning: Identify what the audience needs to understand
- **E**xample: Provide concrete examples
- **A**ction: Specify desired outcomes
- **R**eview: Assess and refine

### 2. **The ARCHITECT Framework**
For system and architectural design:
- **A**nalyze: Requirements and constraints
- **R**esearch: Best practices and patterns
- **C**hoose: Optimal technologies and approaches
- **H**ierarchy: Structure and organization
- **I**ntegrate: Components and systems
- **T**est: Validation and refinement
- **E**xecute: Implementation plan
- **C**elebrate: Success metrics and review
- **T**weak: Optimization and improvements

### 3. **The ITERATIVE Framework**
For continuous improvement and development:
- **I**nitial: First draft or baseline
- **T**est: Evaluate against criteria
- **E**valuate: Analyze results objectively
- **R**efine: Make targeted improvements
- **A**djust: Calibrate approach
- **T**est Again: Validate improvements
- **I**terate: Repeat until satisfied
- **V**erify: Final quality assurance
- **E**xecute: Deploy or finalize

### 4. **The PERSONA Framework**
For creating detailed AI personas:
- **P**urpose: Core mission and values
- **E**xpertise: Knowledge domains and depth
- **R**ole: Specific responsibilities
- **S**tyle: Communication and interaction style
- **O**utputs: Expected deliverables
- **N**uances: Personality quirks and preferences
- **A**djustments: Context-specific modifications

## Best Practices

### 1. **Customization is Key**
- Never use a master prompt verbatim without adaptation
- Replace all placeholders with your specific context
- Add domain-specific constraints and requirements

### 2. **Provide Rich Context**
- The more specific your instructions, the better the output
- Include background information when relevant
- Specify desired tone, format, and style

### 3. **Iterate and Refine**
- First outputs are rarely perfect
- Use feedback to refine your prompts
- Track what works and what doesn't

### 4. **Combine Multiple Spells**
- Use multiple master prompts sequentially for complex tasks
- Chain outputs from one prompt as input to another
- Create custom workflows by combining frameworks

### 5. **Test and Validate**
- Verify outputs meet your quality standards
- Test edge cases and error scenarios
- Validate accuracy and completeness

### 6. **Document Your Variations**
- Keep notes on successful customizations
- Create templates for recurring tasks
- Share learnings with your team

## Advanced Techniques

### Prompt Chaining
Use outputs from one prompt as input to another:

```
Step 1: Use Story Generator → Get story concept
Step 2: Use Character Builder → Develop characters from concept
Step 3: Use Dialogue Master → Create character interactions
Step 4: Use Screenplay Writer → Convert to script format
```

### Context Elevation
Build depth by progressively refining:

```
Level 1: Basic overview (broad prompt)
Level 2: Detailed specification (detailed prompt)
Level 3: Expert analysis (specialized prompt with context)
Level 4: Implementation plan (execution-focused prompt)
```

### Multi-Model Collaboration
Use different AI models for their strengths:

```
Code generation → Claude or GPT-4
Creative writing → GPT-4 or Gemini
Analysis → Claude (better reasoning)
Brainstorming → Any model (vary for different ideas)
```

## Troubleshooting

### Issue: Outputs Are Too Generic

**Solution**: 
- Provide more specific context and constraints
- Use the CLEAR framework to structure your prompt
- Add examples of desired output format

### Issue: Outputs Miss Important Details

**Solution**:
- Use the ARCHITECT framework for systematic thinking
- Break complex requests into numbered, specific items
- Ask the model to "think step-by-step"

### Issue: Results Are Off-Topic

**Solution**:
- Clarify your goal in the first sentence
- Use role-based framing ("You are a [ROLE]")
- End with explicit output specifications

### Issue: Need Variations of the Same Prompt

**Solution**:
- Modify tone, format, or depth parameters
- Use different frameworks for different angles
- Combine multiple spells for richer output
