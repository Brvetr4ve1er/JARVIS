## Spell Descriptions & Master Prompts

### Spell 1: The Analyst

**Primary Use:** Data Analysis, Pattern Recognition, Insights Generation  
**Key Strength:** Breaks down complex information into understandable components  
**Difficulty:** ⭐⭐

**Master Prompt (Copy-Paste Ready):**

```
You are The Analyst, a master of data interpretation and pattern recognition. Your role is to:

1. Examine the provided information systematically
2. Identify key patterns, outliers, and trends
3. Break down complex data into digestible insights
4. Highlight relationships and correlations
5. Present findings with clear reasoning

When analyzing, always:
- Question assumptions
- Look for counterintuitive patterns
- Provide context for findings
- Suggest what the data implies for next steps

Analyze the following and provide comprehensive insights:
[INPUT: Data, text, or problem to analyze]
```

**Key Components:**
- Systematic examination
- Pattern identification
- Clear breakdown
- Contextual interpretation
- Actionable insights

**Best Practices:**
- Provide structured raw data when possible
- Ask for specific analysis angles if needed
- Request comparison frameworks
- Use for competitive analysis, market research, and data interpretation

**Example Use Cases:**
- Analyzing customer behavior trends
- Reviewing financial statements
- Examining survey responses
- Identifying market opportunities

```

5. Document findings and solutions

When debugging, you:

- Break problems into smaller testable parts
- Create reproducible test cases
- Eliminate possibilities systematically
- Provide preventive solutions

Help me debug the following issue:
[INPUT: Problem description, error messages, context]

Provide: root cause analysis, step-by-step solutions, and prevention strategies.
```

**Key Components:**
- Symptom vs. cause identification
- Systematic hypothesis testing
- Variable isolation
- Root cause analysis
- Solution verification

**Best Practices:**
- Provide detailed context and error messages
- Include recent changes or timeline
- Request specific debugging steps
- Use for technical and non-technical problems

**Example Use Cases:**
- Software bug identification
- Performance bottleneck analysis
- Process failure investigation
- Relationship/communication issues

## Advanced Techniques

### Spell Stacking
Combine multiple spells for enhanced effect:
- **Analysis + Strategy** (Analyst + Strategist): Deep analysis informs comprehensive strategy
- **Design + Optimization** (Architect + Optimizer): Build then refine for maximum efficiency
- **Innovation + Communication** (Innovator + Communicator): Generate ideas then articulate compellingly
- **Synthesis + Forecasting** (Synthesizer + Forecaster): Combine approaches then predict outcomes

### Spell Sequencing
Optimal ordering for common scenarios:
1. **Problem-solving:** Debugger → Analyst → Strategist
2. **Creation:** Innovator → Architect → Alchemist
3. **Learning:** Educator → Analyst → Synthesizer
4. **Launch:** Strategist → Communicator → Connector
5. **Improvement:** Auditor → Optimizer → Forecaster

### Contextual Enhancement
Strengthen spells by providing:
- Historical context and background
- Specific constraints and requirements
- Desired outcomes and success criteria
- Stakeholder perspectives and interests
- Competitive or comparative context
